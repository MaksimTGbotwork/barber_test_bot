# Booking Bot

Telegram-бот для онлайн-записи на услуги (демо на примере барбершопа), написан на aiogram 3.

## Стек
- Python 3.13
- aiogram 3.29
- aiosqlite
- python-dotenv
- Деплой: Railway

## Функции
- Выбор услуги через инлайн-кнопки
- Ввод даты и времени с валидацией
- Подтверждение записи перед сохранением
- Просмотр своих записей и их отмена
- Админ-команда для просмотра всех записей

## Команды
- /start — приветствие
- /help — список команд
- /book — записаться на услугу
- /mybookings — мои записи (с возможностью отмены)
- /allbookings — все записи (для владельца)

## Запуск локально
1. Клонировать репозиторий
2. `pip install -r requirements.txt`
3. Создать `.env` с `BOT_TOKEN=твой_токен`
4. `python main.py`
